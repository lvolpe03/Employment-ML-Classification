A comparative design of different machine learning classification models to best predict individual-level employment status using 2024 American Community Survey Data.
- Note: Even compressed, the dataset I used was too large to upload here. However it was extracted from IPUMS and can be easily replicated.

Project Highlights
- Handling factor sparseness
- Engineered variables and interactions to target at-risk groups
- Comparison of models both within and across model families
- Tuning hyperparameters for each ML model type
- Tuning final decision threshold to best manage severe class imbalance in the target class
